# TestDataMaker Ver.1.0

## TestDataMakerとは

TestDataMaker は、システム開発・テストで必要になる **ダミーのテストデータ** を、画面操作だけで大量に作成できる Windows 用ツールです。

「Excel でテストデータを手作業で作る時間を減らす」ことを目的にしています。

- 列名だけの CSV を読み込むと、項目が自動で作成されます
- 日本人名・住所・電話番号・郵便番号・メールアドレス・日付・数値・連番などを生成できます
- NULL の割合や重複禁止を項目ごとに指定できます
- 最大 1,000,000 件まで生成でき、CSV / Excel（.xlsx）で保存できます
- **完全オフラインで動作** します。インターネット通信は一切行いません

## 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / Windows 11（64bit） |
| 必要なソフト | なし（.NET のインストールは不要です） |
| Excel | 不要（Excel がない PC でも .xlsx を出力できます） |
| ディスク | 約 200MB の空き（本体 ＋ 出力ファイル分） |
| メモリ | 4GB 以上推奨（100万件 × 重複禁止項目が多い場合はより多く必要です） |

## インストール方法

1. 配布された `TestDataMaker_v1.0.0.zip` を任意のフォルダに展開します。
   （例：`C:\Tools\TestDataMaker`）
2. `TestDataMaker.exe` をダブルクリックして起動します。

インストーラーはありません。アンインストールはフォルダごと削除するだけです。

> **初回起動時に「Windows によって PC が保護されました」と表示された場合**
> 「詳細情報」→「実行」をクリックしてください。

## 基本的な使い方

```text
起動
 ↓
CSVを読み込む（または「項目を追加」で手動作成）
 ↓
項目ごとにデータ型・NULL率・重複禁止・生成ルールを設定
 ↓
生成件数を入力
 ↓
プレビューで確認
 ↓
「CSV生成」または「Excel生成」で保存
```

### 画面の見かた

| 場所 | 内容 |
|---|---|
| 項目一覧（左） | 項目名・データ型・NULL率・重複禁止を設定します |
| 生成ルール（右） | 一覧で選択した項目の詳細（範囲・形式など）を設定します。下に生成例が表示されます |
| 生成件数 | 1～1,000,000 件の範囲で入力します |
| ステータスバー | 処理結果やメッセージを表示します |

### データ型

| データ型 | 生成例 | 主な設定 |
|---|---|---|
| 文字列 | `aB3xY9kQ` | 使用文字（英数字/英字/数字/ひらがな/カタカナ/任意）、最小・最大文字数、接頭辞 |
| 日本人名 | `山田 太郎` / `ヤマダ　タロウ` | 形式（姓 名 / 姓名 / 姓のみ / 名のみ / カタカナ） |
| 数値 | `25` / `1234.56` | 最小値・最大値・小数桁数 |
| 連番 | `1000, 1001, 1002...` | 開始値・増分 |
| 日付 | `2026/05/13` | 開始日・終了日・日付形式（時刻も可） |
| メールアドレス | `test001@example.com` | ドメイン・連番/ランダム |
| 電話番号 | `090-1234-5678` / `03-1234-5678` | 携帯・固定・混在 |
| 郵便番号 | `100-0001` | なし |
| 住所 | `東京都千代田区中央1丁目2-3` | なし |
| 固定値 | `ACTIVE` | 値 |

### NULL率

0～100% で指定します。例えば 10% にすると、生成件数のおよそ 10% が NULL（空欄）になります。
CSV では空欄、Excel では空のセルとして出力されます。

### 重複禁止

チェックを付けると、その項目の値が重複しないように生成します（NULL は重複の対象外です）。
条件上、必要な件数の値を作れない場合はエラーになります。

> 例：年齢 18～80（63種類）で重複禁止・1万件 → 「指定された条件では10000件のユニークデータを生成できません。」

## CSV読み込み

1. 「CSVを読み込む」をクリックし、CSV ファイルを選択します。
   **または、CSV ファイルを画面にドラッグ＆ドロップします。**
2. 1 行目の列名が項目一覧に読み込まれます。
3. 列名（例：`ID`、`NAME`、`氏名`、`BIRTHDAY`、`EMAIL`、`TEL` など）から、データ型を自動で推測します。
   推測が違う場合は一覧で変更してください。

- 対応する文字コード：**UTF-8（BOM あり/なし）、Shift-JIS** （自動判別）
- 2 行目以降のデータは、型の推測にのみ使用します

## データ生成

1. 生成件数を入力します（既定：1,000 件、最大 1,000,000 件）。
2. 「プレビュー」で先頭 100 件を確認します。
3. 「CSV生成」または「Excel生成」をクリックし、保存先を選びます。
   ファイル名の初期値は `testdata_yyyyMMdd_HHmmss.csv` です。
4. 生成中は進捗バーと件数が表示されます。「キャンセル」で中止できます（途中のファイルは残りません）。

生成時間の目安（Core i5 クラスの PC・6項目の場合）：

| 件数 | CSV | Excel |
|---|---|---|
| 100,000 件 | 1 秒未満 | 約 2 秒 |
| 1,000,000 件 | 約 4 秒 | 約 20 秒 |

### CSV出力

- 文字コード：UTF-8
- 「CSVをBOM付きUTF-8で出力」にチェックがある場合（既定）、Excel でそのまま開いても文字化けしません。
  BOM を付けたくない場合（他のシステムに取り込む場合など）はチェックを外してください。
- 改行コード：CRLF
- カンマ・ダブルクォート・改行を含む値は `"` で囲みます

## Excel出力

- 形式：.xlsx（Excel 2007 以降）
- シート名：`TestData`
- 1 行目：ヘッダー（太字・ウィンドウ枠固定）
- 2 行目以降：生成データ
- 数値・連番の項目は数値として出力します（その他は文字列）
- Excel がインストールされていない PC でも出力できます

## 設定保存

現在のデータ定義（項目名・データ型・生成ルール・NULL率・重複禁止・生成件数）を JSON ファイルに保存できます。

- 「設定を保存」（Ctrl+S）：JSON ファイルに保存します（例：`customer_testdata.json`）
- 「設定を読み込む」（Ctrl+O）：保存した定義を読み込みます。JSON ファイルのドラッグ＆ドロップでも読み込めます

チームで同じ定義を共有したい場合は、JSON ファイルを共有してください。

## FAQ

**Q. インターネットに接続していない PC でも使えますか？**
A. はい。すべての処理は PC 内で完結します。氏名・住所などのデータもアプリに内蔵しています。

**Q. 入力したデータや生成したデータが外部に送信されることはありますか？**
A. ありません。TestDataMaker はインターネット通信を一切行いません。

**Q. 生成される氏名・住所・電話番号は実在しますか？**
A. 一般的な姓・名、市区町村名をランダムに組み合わせたダミーデータです。特定の個人を表すものではありませんが、偶然実在する組み合わせになる可能性はあります。
テストデータを外部に送信・公開しないでください。メールアドレスには `example.com` などテスト用ドメインの使用をおすすめします。

**Q. CSV を Excel で開くと文字化けします。**
A. 「CSVをBOM付きUTF-8で出力」にチェックを付けて出力し直してください。

**Q. CSV の読み込みでエラーになります。**
A. 次を確認してください。
- 拡張子が `.csv` であること
- 1 行目に列名があること
- 文字コードが UTF-8 または Shift-JIS であること

**Q. 保存時に「ファイルを保存できませんでした」と表示されます。**
A. 同じ名前のファイルを Excel などで開いていないか、保存先フォルダに書き込み権限があるか確認してください。

**Q. 毎回同じデータを生成できますか？**
A. Ver.1 では毎回異なるデータを生成します。同じデータを再現する機能（Seed 指定）は今後のバージョンで対応予定です。

**Q. エラーの詳細を確認したい。**
A. 「ヘルプ」→「ログフォルダを開く」でログを確認できます。
ログの保存先：`%LOCALAPPDATA%\TestDataMaker\logs\`
ログにはエラー内容のみを記録し、生成データは記録しません。30 日より古いログは自動で削除されます。

**Q. アンインストールするには？**
A. フォルダごと削除してください。ログも不要な場合は `%LOCALAPPDATA%\TestDataMaker` フォルダも削除してください。レジストリは使用していません。

## 開発者向け情報

### 構成

```text
TestDataMaker.sln
├── src/TestDataMaker.Core    … 画面に依存しない処理（.NET 8 クラスライブラリ）
│   ├── Models                … データ定義（FieldDefinition など）
│   ├── Generators            … 各データ型の値生成（String/Name/Number/Sequence/Date/Email/Phone/PostalCode/Address/Fixed/Null）
│   ├── Services              … DataGeneration / Csv / Excel / Config / Validation / AppLogger / FieldTypeInferrer
│   └── Data                  … 内蔵の姓名・住所データ
├── src/TestDataMaker         … Windows Forms の画面（UI）
├── tests/TestDataMaker.Tests … xUnit によるユニットテスト
├── sample                    … 配布用サンプル
└── tools                     … ビルド・アイコン生成スクリプト
```

### ビルド・テスト

.NET 8 SDK が必要です。

```powershell
dotnet build TestDataMaker.sln
dotnet test
dotnet run --project src\TestDataMaker
```

### 配布物の作成

```powershell
powershell -ExecutionPolicy Bypass -File tools\publish.ps1
```

`dist\TestDataMaker_v1.0.0\` と `dist\TestDataMaker_v1.0.0.zip` が作成されます（.NET ランタイム同梱の単一 exe）。

### 機能追加の方法

- **データ型の追加**（UUID・IP アドレス等）：`ValueGenerator` を継承したクラスを作り、`DataType` と `GeneratorFactory` に追加します。
- **出力形式の追加**（Oracle / SQL Server / PostgreSQL / MySQL の INSERT 文、JSON、XML 等）：`IDataExporter` を実装します。
- **Seed 指定**：`GenerationOptions.Seed` を指定すると同じデータを再現できます（内部対応済み・画面は未対応）。
- **コマンドライン実行**：処理はすべて `TestDataMaker.Core` にあるため、コンソールアプリから同じ Service を呼び出せます。
